# RBA-TOOL Frontend Application

The frontend for **RBA-TOOL** is a modern React application built with Vite, Material UI (MUI), and interactive data visualization libraries (ApexCharts, D3, Leaflet).

---

## 📁 Directory Structure

```
frontend/
└── rbafront/                 # Primary React application root
    ├── src/                  # React source components, views & services
    ├── public/               # Public static assets
    ├── package.json          # Dependency specifications & scripts
    ├── vite.config.js        # Vite bundler configuration
    ├── .env.example          # Environment variables template
    └── README.md             # Detailed frontend documentation
```

---

## 🚀 Quick Start

1. Navigate to the application root:
   ```bash
   cd rbafront
   ```

2. Install npm dependencies:
   ```bash
   npm install
   ```

3. Set environment configuration:
   ```bash
   cp .env.example .env
   ```

4. Start development server:
   ```bash
   npm run dev
   ```
